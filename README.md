# 마을이음 호스트 모집 랜딩페이지

## 📋 프로젝트 개요
'마을이음' 한국형 오테츠타비 플랫폼의 호스트 파트너를 모집하기 위한 랜딩페이지입니다. 인건비 부담 없이 빈방과 식사 제공만으로 성수기 일손 문제를 해결하는 상생 모델을 소개합니다.

## 🎯 타겟
- 소상공인, 농가, 펜션/카페 운영자
- 시기별 일손 부족으로 고민하는 사업주

## 🚀 기술 스택
- HTML5
- CSS3 (Responsive Design)
- Vanilla JavaScript
- GitHub Pages (배포)

## 📁 파일 구조
```
country-connect-landing/
├── index.html          # 메인 랜딩페이지
├── css/
│   └── style.css       # 스타일시트
├── js/
│   └── main.js         # 인터랙션 기능
└── assets/
    ├── images/         # 이미지 파일
    └── icons/          # 아이콘 파일
```

## 🎨 디자인 특징
- **컬러**: 따뜻한 주황색(#FF6B35) 기반
- **폰트**: Noto Sans KR
- **반응형**: 모바일 우선 설계
- **애니메이션**: 스크롤 기반 애니메이션 효과

## 📱 주요 섹션
1. **히어로**: 메인 카피와 CTA
2. **문제 제기**: 타겟의 고민점 공감
3. **솔루션**: Give & Take 개념 소개
4. **핵심 혜택**: 비용 절감, 마케팅 효과, 유연 인력
5. **진입 장벽 제거**: 숙소 연결 솔루션
6. **이용 프로세스**: 4단계 안내
7. **가입 유도**: 체크리스트와 얼리버드 혜택

## ⚙️ 기능
- 상담 신청 모달 폼
- 전화번호 자동 포매팅
- 스크롤 애니메이션
- 반응형 네비게이션
- 카드 호버 효과
