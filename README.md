# 마을이음 (Maeul-Leum) 랜딩 페이지

여행이 일손이 되는 상생 플랫폼 - 서울 근교 여행과 단기 체류, 지역 일손 돕기를 안전하게 매칭합니다.

## 🚀 시작하기

로컬 개발 서버를 실행하세요:

```bash
# Python이 설치된 경우
npm run dev

# 수동으로 서버 시작
python -m http.server 8080 --directory .
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 열어 결과를 확인하세요.

## 📁 프로젝트 구조

```
├── index.html          # 메인 HTML 파일
├── css/
│   └── style.css      # 모든 스타일 (CSS Variables, Grid, Animations)
├── js/
│   └── main.js        # 바닐라 JavaScript (Classes, Events, Animations)
└── assets/            # 이미지 및 정적 파일
```

- **모바일 우선 반응형 디자인**
